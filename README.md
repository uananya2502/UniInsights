# 🎓 UniInsights

**UniInsights** is an AI-powered university intelligence platform that helps students make informed decisions about universities using data-driven insights from student feedback and online content.

## 🚀 Features

* 🏫 **University Report Card** – Get an overall view of a university.
* ⚖️ **University Comparison** – Compare universities using different insights.
* 💬 **Student Feedback Analysis** – Analyze opinions using **VADER Sentiment Analysis**.
* 📊 **Topic Analysis** – Discover major discussion topics using **TF-IDF and LDA**.
* 📰 **Intelligence Feed** – Track important university-related discussions and trends.
* 🤖 **Ask Seniors AI** – Ask questions and get contextual answers using **Gemini + RAG**.
* 🔎 **Full-Text Search** – Retrieve relevant information using **SQLite FTS5**.
* 📈 **Reputation Timeline** – Understand how university discussions change over time.

## 🛠️ Tech Stack

**Python • YouTube Data API v3 • VADER • TF-IDF • LDA • SQLite/FTS5 • Gemini • RAG**

## 🎯 Goal

To transform scattered student feedback and online information into **simple, meaningful, and actionable university insights**.

> **UniInsights — Turn student voices into university intelligence.**
